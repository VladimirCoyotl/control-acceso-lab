# Control de Acceso Lab

Laboratorio de control de acceso (RBAC, ABAC, ReBAC, MFA, ACL de red, IoT y auditoría).

- `npm test` ejecuta las pruebas y la matriz P01-P15 (falla si alguna no coincide).
- `npm run build` ejecuta las pruebas y genera `dist/index.html`, que se publica en Azure Static Web Apps.
